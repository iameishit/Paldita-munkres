# Getting help

- **Usage questions**: read the [README](README.md) and the [docs](docs/index.md)
  ([troubleshooting](docs/troubleshooting.md), [FAQ](docs/faq.md)), then open a
  [GitHub issue](https://github.com/iameishit/Paldita-munkres/issues/new/choose) using the documentation or feature template.
- **Something looks wrong**: open a bug report with a minimal matrix that reproduces it.
- **Security problems**: never use public issues. See [SECURITY.md](SECURITY.md).

This is a volunteer-maintained project; responses are best-effort.
