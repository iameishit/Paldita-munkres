# Roadmap

munkres 2 puts correctness, stability and a small dependency-free core first. Directions that may
be explored in later releases, depending on user feedback:

- an auction-based solver for very sparse problems
- matching inside a single group (general graphs)
- updating an existing solution when rows or columns are added
- a documentation website with interactive traces

Ideas and requests are welcome through [issues](https://github.com/iameishit/Paldita-munkres/issues/new/choose).
